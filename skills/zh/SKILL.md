# Antigravity 账号管理器 (zh)

终端可视化多账号管理、方向键原生交互式选择，全面支持中英文指令与中文账号别名，切换后默认自动重载会话。

## 执行方式

当用户输入 `/zh` 或要求查看/切换/重载账号时，直接执行对应命令：

- 原生交互选择器（支持方向键 ↑/↓ 选择，Enter 确认并默认自动重载）：`zh`
- 唤起方向键独立交互窗口：`zh 窗口` 或 `zh ui`
- 查看面板与列表：`zh 列表` 或 `zh list`
- 切换账号（默认自动重新载入会话）：`zh <序号或别名>` 或 `zh 切换 <序号或别名>`
- 自动添加新账号：`zh 添加 [别名]` 或 `zh add [别名]`
- 保存当前登录账号：`zh 保存 <别名>` 或 `zh save <别名>`（全面支持中文别名）
- 删除已保存账号：`zh 删除 <别名>` 或 `zh rm <别名>`
- 重新载入当前会话：`zh 重载` 或 `zh reload`
- 查看活动账号详情：`zh 状态` 或 `zh whoami`
